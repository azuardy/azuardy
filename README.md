<details>
  <summary><b>📖 Aturan Permainan (How to Play)</b></summary>
  <br/>
  <ol align="left">
    <li>Mulai dari kotak <b>🚀 START (A1)</b>.</li>
    <li>Pada setiap kotak, kamu harus melangkah lurus searah dengan <b>tanda panah</b>.</li>
    <li>Kamu bebas melangkah <b>1, 2, atau 3 kotak</b> sepanjang garis lurus tersebut selama masih di dalam area papan.</li>
    <li>Temukan rute langkah yang tepat untuk mencapai <b>🎯 GOAL (D4)</b>! Hati-hati dengan jalan buntu dan jebakan berputar!</li>
  </ol>
</details>

<details>
  <summary><b>💡 Petunjuk (Hint)</b></summary>
  <br/>
  <p align="left">Dari posisi awal <b>A1 ➡️</b>, jangan melangkah hanya 1 kotak karena kamu akan memantul bolak-balik. Coba lompat 2 kotak ke kanan!</p>
</details>

<details>
  <summary><b>🏆 Kunci Jawaban & Rute (Solution)</b></summary>
  <br/>
  <p align="left">
    <b>Jalur 6 Langkah Kemenangan:</b><br/>
    1. <b>A1 (➡️)</b> Lompat 2 langkah ke kanan ➔ <b>A3</b><br/>
    2. <b>A3 (⬇️)</b> Lompat 2 langkah ke bawah ➔ <b>C3</b><br/>
    3. <b>C3 (⬅️)</b> Lompat 2 langkah ke kiri ➔ <b>C1</b><br/>
    4. <b>C1 (↗️)</b> Lompat 1 langkah diagonal kanan-atas ➔ <b>B2</b><br/>
    5. <b>B2 (⬇️)</b> Lompat 2 langkah ke bawah ➔ <b>D2</b><br/>
    6. <b>D2 (➡️)</b> Lompat 2 langkah ke kanan ➔ <b>🎯 D4 (GOAL)!</b> 🎉
  </p>
</details>
